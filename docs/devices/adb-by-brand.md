# 各品牌电视怎么打开 ADB

安装 Aerial 之前要先在电视上打开 ADB 调试。各品牌的入口不一样，下面按品牌列出。
路径和说法来自用户反馈、[issue #32](https://github.com/pengchujin/aerial-tv/issues/32) 的评论，
以及同目录下的机型笔记；没有单独注明的都还没有在本仓库的真机上验证过。

## 小米 / Redmi

设置 → 关于 → 连续按遥控器确认键点 **产品型号**，直到提示进入开发者模式；
再到 设置 → 账号与安全，打开 **ADB 调试** 和 **安装未知来源的应用**。

- 小米 / 红米电视、小米显示器 G Pro 都是这个路径。
- 打开一次即可，重启后仍然有效。小米待机后可能会自己关掉，安装时加 `KEEP_ADB=1` 可以让 Aerial 再打开。

## TCL / 雷鸟

设置 → 关于 → **本机信息**，在一秒内依次按遥控器 **上、下、左、右**，底部出现「更多」，
在里面打开 **ADB**。

## OPPO（含 S1）

1. 设置 → 系统 → 关于本机 → **设备型号**，按遥控器 **上、上、右、右**，再按确认。
   页面会提示「还需执行 N 步」，按对了才会出现开发者选项。
2. 设置 → 系统 → **开发者选项**，打开 **USB 调试**（有的机型叫「ADB 调试」）。
3. IP 在 设置 → 网络 → 已连接的网络 的**最下面**。

ColorOS TV 的更多限制（比如只认三个固定包名当桌面）见 [oppo-coloros-tv.md](oppo-coloros-tv.md)。

## 海尔 / 模卡（MOOKA）

按**电视机身上**的信号源键，弹出信号源菜单后，用遥控器依次按 **左、左、上、右**，
进入「海尔工厂菜单」，把 **ADB 调试开关** 设为开（有的机型在第二页 Other Option → adb debug）。
只改这一项，别动其他选项，尤其不要选「工厂复位」。

## 原生 Android TV / Google TV、索尼、海信等

设置 → 设备偏好设置 → 关于 → 连续按 **内部版本号**（Build，不是「Android 版本」）7 次，
再到开发者选项打开 **USB 调试**（也可能叫「网络调试」）。

**只有无线调试、没有 USB 调试 / 网络调试（ADB 调试）开关的 Android 11+ 电视**（例如索尼 BRAVIA
的 Android 14，#747）：这类电视要先配对，不能像低版本那样直接 `adb connect <电视IP>:5555`。
打开 无线调试 → **使用配对码配对设备**，在电脑上运行：

```bash
adb pair <电视IP>:<配对屏上的端口>   # 再按提示输入电视上的 6 位配对码
adb connect <电视IP>:<无线调试主页上的端口>   # 和上面不是同一个端口
```

连上后照常 `adb install`、授权。想以后直接用 `<电视IP>:5555`，连上时运行一次 `adb tcpip 5555`；
这台电脑已经配对过，不用再配对。`install.sh` 和 `site/agent.md` 会引导这一步。
部分同平台的 TCL 固件没有配对码入口：Q10M（[#31](https://github.com/pengchujin/aerial-tv/issues/31)
的实机反馈，只有动态端口，没有无线调试详情页）。鹤 6 Ultra（Android 14）上有用户用 USB A 对 A 线
把电视连到电脑（电脑插 USB 3.0 口、电视插 USB 2.0 口），先走有线 adb 授权，再执行一次 `adb tcpip 5555`，见 [tcl-mt9655-cn.md](tcl-mt9655-cn.md)。

海信 VIDAA 的额外设置见 [hisense-vidaa.md](hisense-vidaa.md)。

## 极米

设置里通常没有开发者选项，连点版本号无效。

- **H3**：手机下载 [code-ant/z7x-adb](https://github.com/code-ant/z7x-adb) 的 APK，用极米手机 App 上传到投影仪并安装，打开一次即可。见 [xgimi-h3.md](xgimi-h3.md)。
- **Z7X**：用 U 盘安装同一个工具并打开一次。见 [xgimi-z7x.md](xgimi-z7x.md)。
- 目前只有这两台有本仓库的用户实测，不代表所有极米型号。

## 打不开 ADB 的机型

这些机型目前没有办法，不用反复尝试：

- 老乐视
- 荣耀智慧屏
- 老康佳（设置里看不到版本号）

当贝投影 F5 等机器，有用户用第三方工具 [BuddhaYi/android-tv-developer-enabler](https://github.com/BuddhaYi/android-tv-developer-enabler)
打开过 ADB。那不是本项目的工具，也不是官方推荐：请自行评估风险，本项目不担保。

## 没有电脑

有用户用手机上的「甲壳虫 ADB 助手」「超级小爱」装成功过，本仓库没有逐一实测。
大致步骤和电脑一样：手机连同一个 Wi-Fi，连到 `<电视IP>:5555`，在电视上选「始终允许」，
再用工具安装 APK、授予权限。手机工具一般不能执行全部命令，装好后最好再用电脑或 Agent 跑一遍
[验收](../../site/agent.md#验收必须做)。
