Aerial

A calm home screen for Android TV. No ads, no recommendation feeds. Just your apps, your wallpaper and Apple TV's aerial screensavers.

Home

As easy as
Apple TV.

Your favorite apps sit in one row on a glass shelf. The focused one lifts gently and casts a soft shadow.

A white ring marks focus, easy to spot from the couch. Hidden system apps like Xiaomi's App Store and Mi Home show up too.

Organize

Folders

Control Center

Wallpaper

Set up from your phone

Scan.
Don't type.

Scan the code on the TV to arrange Home on your phone (drag to reorder, rename, change icons, folders, hide, add HDMI), upload photos, pick a wallpaper or change the screensaver.

Home at boot.
Still home after standby.

Most TVs sold in China lock you into the maker's launcher and kill other apps in standby. Aerial works around both, with no root and no system apps disabled.

Owns the Home button

Aerial becomes the default home screen where it can; elsewhere, Home Guard brings it back. The stock launcher is still there.

Back in half a second

Xiaomi TVs force-stop other apps in standby. Android brings Aerial right back.

Survives a power cut

Aerial takes over at boot. The installer gets it past TCL's startup block.

Up and running
in three minutes.

No root, and you can undo it any time.

1Turn on ADB debugging on the TV

Settings (设置) → About (关于) → press OK on Model (产品型号) until developer mode is on. Then Settings → Account & Security (账号与安全): turn on ADB debugging (ADB 调试) and Install unknown apps (安装未知来源的应用).
The IP address is under Settings → Network → the connected network.

Settings (设置) → About (关于) → Device info (本机信息), then quickly press Up, Down, Left, Right. Turn on ADB in the More (更多) group that appears.
The IP address is under Settings → Network → the connected network.

Press the Source button on the TV itself. While the source menu is open, press Left, Left, Up, Right on the remote to open the factory menu (海尔工厂菜单), then set ADB 调试开关 (ADB debugging) to on. Change nothing else.
The IP address is under Settings → Network → the connected network.

Settings (设置) → System (系统) → About (关于本机) → Model (设备型号), press Up, Up, Right, Right, then OK. Then Settings → System → Developer options (开发者选项) and turn on USB debugging (USB 调试, sometimes called ADB debugging).
The IP address is at the bottom of Settings → Network → the connected network.

Settings → Device Preferences → About → press Build (not Android version) 7 times, then turn on USB debugging in Developer options.
The IP address is under Settings → Network → the connected network.

Some TVs cannot open ADB at all: XGIMI H3, old LeTV sets, Honor Vision and old Konka models (no version number to tap).

2Enter the TV's IP address

It's under Settings → Network → the connected network (at the bottom on OPPO S1). Your computer must be on the same network.

FAQ

    

      

        Can I install it straight from a web page?
        
No. Browsers can't reach the TV's ADB. The agent prompt or the one-line command is the easiest way.

      

      

        Can it break my TV? How do I undo it?
        
No. Aerial doesn't touch system apps; it grants itself a few permissions and changes the home screen and screensaver settings, and all of that can be undone. The easiest way is to paste the text below into an AI that can run commands on a computer (the same kind you installed with): it follows the Undo section of the install guide, undoes every change and leaves the TV on its original home screen. Add "and uninstall Aerial as well" to also remove it.

        

        
By hand: replace the final bash in the one-line command with bash -s restore, that is curl -fsSL https://aerial.qust.me/install.sh | TV=<TV-IP> bash -s restore; add --uninstall to remove Aerial too. On Windows without bash, the commands one by one are in the install guide.

      

      

        My firmware won't install home-screen apps?
        
Install the build that doesn't declare itself a home screen: add -s guard to the end of the one-line command, or download aerial-guard.apk for a manual install.

      

      

        Do my subscriptions, Xiaoai, Xiaomi account or cable TV change?
        
No. Aerial only replaces the home screen: Xiaomi / TCL subscriptions, Xiaoai, your Xiaomi account and cable TV all work as before, and the old home screen still opens from the app list.

      

      

        Where did Xiaomi Video and PatchWall content go?
        
The 桌面 (Home) tile opens PatchWall as before, with its recommendations and subscription content. The boot ad comes from the firmware; Aerial can't remove it.

      

      

        The agent says it's installed, but nothing changed on the TV?
        
Some agents report success without running anything. Ask it to paste the raw output from "Check" in the install guide: which home screen resolve-activity finds, whether enabled_accessibility_services contains app.orchard.tv, and the mCurrentFocus after pressing Home. The install only worked if the last one includes app.orchard.tv.

      

      

        Can I install it with only a phone?
        
You can try. Users have installed Aerial with Beetle ADB (甲壳虫 ADB 助手) and Super Xiaoai (超级小爱) on a phone; we haven't tested each one. See "Phone only" under Install.

      

      

        How do I update?
        
From 1.32, the TV's Control Center shows New Version when there is one: choose Download and Install, then confirm in the TV's own installer. On TVs that do not let apps install apps, updating means running the install command again (or asking the agent again); the update page has a QR code that opens this TV's command on a phone. Settings, layout and wallpaper are kept.

      

      

        What permissions does it use?
        
WRITE_SECURE_SETTINGS turns Home Guard back on if it's switched off. The notification listener lets Android restart Aerial; it reads no notifications. Accessibility only sees which window is in front, not what's on screen. Location only shows your Wi-Fi name.

      

      

        Where do the aerial films come from? How much data do they use?
        
They stream straight from Apple's servers in 1080p, at about 15–20 Mbps. If they can't load, Aerial switches to the photo screensaver.

      

      

        Will it work on my TV?
        
Check the list. If yours isn't there, probably. Stock Android TV and Google TV are the easiest. LG webOS, Samsung Tizen and Huawei Vision (HarmonyOS) run different systems and can't take Aerial; Android 4.4 or older can't either (Aerial needs Android 5.0). Some TVs can't open ADB at all, such as XGIMI H3, old LeTV sets, Honor Vision and old Konka models (no version number to tap). Slow or low-memory TVs pick Lite effects on their own; you can also choose it in Personalize → Effects. If something goes wrong, tell us with the device support form and its diagnostics: run curl -fsSL https://aerial.qust.me/tools/report.sh | TV=<tv-ip> bash on a computer, or copy them from More → Report a Problem on the phone page.
