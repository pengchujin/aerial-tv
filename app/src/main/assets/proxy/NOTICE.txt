THE CORE IS NOT PART OF THIS SOURCE TREE. Aerial's code only starts and talks to it; it builds and
runs without it (the VPN button then reports that the core is unavailable). It is fetched on
request, unmodified, from the official release by tools/fetch-mihomo.sh (tools/fetch-mihomo.ps1 on
Windows), which checks both SHA-256 values below and installs it as the git-ignored file
app/src/main/jniLibs/armeabi-v7a/libmihomo.so. It runs as a separate child process, not loaded by
JNI; the .so name only makes Android's PackageManager extract it from the APK.

Official linux-armv7 release asset (statically linked, built with the with_gvisor tag):
https://github.com/MetaCubeX/mihomo/releases/download/v1.19.33/mihomo-linux-armv7-v1.19.33.gz

Uncompressed executable SHA-256: e9eaf8ad3467ca980af75abab56969ed7167b4d7a0dd63cd4a112004e4a39fcc
The linux build is used on Android because its TUN inbound accepts the Android VpnService file
descriptor without reading the system package list, which ordinary apps cannot read.

Anyone who builds an APK that bundles the core (that is, after running the fetch script) distributes
a GPLv3 program and must meet the GPLv3 for it: offer the corresponding source (the link above is
the exact tag), keep MIHOMO-LICENSE with the APK, and pass the same rights on. The core is
unmodified. Aerial's own code stays under its own license (the project's LICENSE); the core and
Aerial communicate only through a loopback HTTP controller and a file descriptor.
No affiliation with or endorsement by MetaCubeX is claimed.

Download button: a build without the bundled core offers "Download the core" on the VPN page (TV)
and the Proxy tab (phone page), on TVs that can run 32-bit ARM code. Nothing is downloaded until
the user presses it. The file comes from the URL list in proxy/CoreSources.kt over https, and is
used only if its compressed size and SHA-256 and its extracted size and SHA-256 equal the values
above (checked before decompressing, and again before it is made executable); otherwise it is
deleted. The core stays unmodified and GPLv3, as above.
