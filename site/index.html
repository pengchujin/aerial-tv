常见问题

    

      

        能不能打开网页就直接装到电视上？
        
不能。网页连不上电视的 ADB。最省事的是上面的 Agent 提示词或一行命令。

      

      

        会不会把电视弄坏？怎么还原？
        
不会。Aerial 不动系统应用，只授予几项权限、改了桌面和屏保设置，这些都能撤销。最省事的还原方法是把下面这段直接发给 AI（和安装时一样，要用能在电脑上运行命令的版本），它会按安装说明的「还原」一节撤销全部改动，最后用主页键回到原来的桌面。想连 Aerial 一起卸载，在提示词最后加一句「顺便卸载 Aerial」。

        

        
自己动手也可以：把一行命令最后的 bash 换成 bash -s restore，也就是 curl -fsSL https://aerial.qust.me/install.sh | TV=<电视IP> bash -s restore；最后加 --uninstall 会顺便卸载 Aerial。不能运行 bash 的 Windows，逐条命令见安装说明。

      

      

        提示固件不允许安装桌面类 App？
        
改装不声明桌面的版本：一行命令最后加 -s guard，手动安装就下载 aerial-guard.apk。

      

      

        会员、小爱同学、小米账号和有线电视受影响吗？
        
都不受影响。Aerial 只换桌面：小米 / TCL 的会员、小爱同学、小米账号、有线电视都照常使用，原来的桌面也能从 App 列表打开。

      

      

        小米影视、PatchWall 的内容去哪了？
        
从「桌面」磁贴进去就是原来的 PatchWall，推荐和会员内容都在。开机广告是固件播的，Aerial 去不掉。

      

      

        Agent 说装好了，电视上却没变？
        
有的 Agent 没运行命令就说成功了。让它按 安装说明 的「验收」把原始输出贴出来：resolve-activity 解析到的桌面、enabled_accessibility_services 里有没有 app.orchard.tv、按主页键后的 mCurrentFocus。最后一条里有 app.orchard.tv 才算装好。

      

      

        没有电脑，只用手机能装吗？
        
可以试。有用户用手机上的甲壳虫 ADB 助手、超级小爱装成功过，我们没逐一实测。步骤见安装区的「只用手机」。

      

      

        怎么升级？
        
1.32 起，有新版本时电视的控制中心会出现「有新版本」，选「下载并安装」，再在电视自己的安装界面确认就行。电视不让 App 安装应用时，升级就是再运行一次安装命令（或者再交给 Agent 一次）：升级页上有二维码，手机扫码能复制这台电视的命令。设置、排列和壁纸都会保留。

      

      

        需要哪些权限？
        
WRITE_SECURE_SETTINGS：桌面守护被关掉后重新打开。通知监听：被杀后由系统拉起，不读通知。无障碍：只看哪个窗口在前台，不读屏幕内容。定位：只用来显示 Wi-Fi 名称。

      

      

        航拍影片从哪来？费流量吗？
        
直接从 Apple 的服务器播放，1080p，码率约 15–20 Mbps。连不上时自动改用照片屏保。

      

      

        我的电视能用吗？
        
先看机型列表。不在列表里的大概率也可以，原生 Android TV / Google TV 最省事。LG webOS、三星 Tizen、华为鸿蒙智慧屏的系统不一样，装不了；Android 4.4 及更老的电视也不行（Aerial 最低要 Android 5.0）。极米 H3、老乐视、荣耀智慧屏、老康佳（看不到版本号）等机型打不开 ADB，暂时没有办法。老电视或内存小的电视会自动用「流畅」效果，也可以在 个性化 → 效果 里手动选。遇到问题请用 机型适配模板 告诉我们，附上诊断信息：电脑上运行 curl -fsSL https://aerial.qust.me/tools/report.sh | TV=<电视IP> bash，或在手机配置页「更多 → 反馈问题」里复制。
