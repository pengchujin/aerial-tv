# 设计

用户已批准范围，并授权后续设计、任务安排、实现和真机验证自主推进。

## 体验规格

目的：在小米方向键遥控器上获得清晰、连贯、低延迟的电视桌面体验。
风格：影院式背景、轻玻璃面板、明确的悬浮焦点；沿用现有 tvOS 视觉体系。
颜色：背景 #000000、主文字 #FFFFFF、次文字 #EBEBF5（60%）、玻璃 #202022、聚焦面板 #F5F5F7。
字体：沿用已获 OFL 授权的 Inter Text / Display，遵循项目原有设计系统，不引入 Apple 字体。
布局：保留 960×540dp、五列磁贴和顶部状态区；玻璃底板与焦点名称避免碰撞。
动效：磁贴与普通控件采用同一临界阻尼焦点弹簧；装饰变化只在 draw / layer 阶段读取动画状态；边缘反馈可中断，不积压协程。

## 实施结构

- 增加 preview flavor，独立包名、端口，禁用守护、开机接管、同步账号、上游更新；文件 provider 沿用 applicationId。
- preview 同一包名先构建基线，再覆盖安装候选版，保持测试数据一致。官方安装不覆盖。
- AppTile：把动画阈值的组合观察转换成 derivedStateOf；复用高光 shader，消除逐帧对象分配；轮廓等预烘焙结果仍沿用原缓存。
- HomeViewModel：合并重复系统探测请求，耗时 binder 查询移出主线程；应用与信号源查询并发但原子提交。
- 统一控件焦点弹簧并修复边缘按键的中断行为。
- 工具记录原始 gfxinfo、内存、启动数据及截图；冷启动采用 force-stop 的 preview 进程，不扰动官方守护。

## 验证

release 构建、单元测试、lint 新增错误审查；同包名同设备前后至少 10 次启动、每场景 5 轮采集，报告分位数与边界。无法达到的目标列为未达标。官方 HOME 接管保持原状，preview 使用显式 Activity 启动；最终默认桌面的切换与数据迁移不混入性能测试。
