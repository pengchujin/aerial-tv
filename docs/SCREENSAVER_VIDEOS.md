# 史努比壁纸与视频屏保

## 史努比

控制中心 → 个性化 → 壁纸 →「史努比」。它与航拍、每日一图并列，遥控器可直接选择。第一次选择会从 [hitnology/snoopy 0.2.2](https://github.com/hitnology/snoopy/releases/tag/0.2.2) 下载素材，显示进度，可取消、失败后按确认重试。下载期间可以选择其他壁纸，完成后不会替用户切回来。

需要下载约 550 MB，最终保留约 400 MB 的 12 段 1080p HEVC 录屏；之后离线播放，不需要电脑转码或手机导入。电视需要能解码这些 HEVC 影片。主屏幕第一行停留 10 秒后开始播放，按任意键暂停在当前画面，玻璃背景跟着更新，下次从这里继续。选过的画面在重启应用后保留。

屏幕保护程序里也有独立「史努比」选项。新安装、尚未手动选择过屏保时，选择史努比壁纸会让屏保跟随；已经手动选择过的屏保保持原选择，可在同一页改成史努比，再按「立即开始」。主页影片已在播放时可衔接进入屏保，左右键切片，其他键唤醒。

该发布包的素材为 Apple tvOS 史努比屏保的录屏。下载只提取其中确认的 12 段完整录屏，每段检查固定大小和 SHA-256；不提取 macOS 可执行文件或需要 HEVC 透明通道的旧分层动画。录屏开头的箭头仍会保留。这是这些录屏的 Android 壁纸/屏保适配，不是 macOS 播放器的完整移植。APK 不包含动画素材。

## 自定义视频

控制中心 → 个性化 → 屏幕保护程序 →「视频」。用手机扫描同一页的二维码，在手机页选「视频」后添加 MP4 或 MOV；可以多选，逐个上传。上传不会替用户选择屏保，也不改变壁纸。

影片保存在电视本机，静音、随机排列后循环播放；左右键切上一段、下一段，其他键唤醒。没有影片，或所有影片都打不开时，回退到照片屏保。手机页可以逐段删除。自定义视频库与下载的史努比素材分开保存，互不替换或删除。

建议 1080p H.264，兼容 Android 5.0 起的电视。其他编码取决于电视自己的解码器；不在电视上转码。每段上限 200 MiB，共 512 MiB，最多 64 段。大批上传时电视只需要为当前一段保留临时空间。

## 实现

- `Snoopy` 在独立私有目录 `files/snoopy/0.2.2/` 保存下载的素材。暂存、逐片校验完成后才发布；解压路径使用固定白名单，限制下载量和解压总量。下载与 UI 分离，不因界面关闭而切换用户的选择。
- 史努比壁纸复用 `LiveWallpaper` 的空闲播放、暂停画面、磨砂背景和屏保衔接；与航拍分别保存影片及暂停位置。
- `ScreensaverVideos` 管理应用私有目录 `files/screensaver-videos/`。上传先校验视频轨和时长，优先移动到暂存目录、失败时复制，再原子改名发布；删除只接受本库生成的 ID。
- `VideoSaver` 使用 Media3、本地文件和一个有界缓冲的播放列表。影片打不开或 8 秒仍不能播放，就从本轮队列移走；不会因为解码失败删除用户文件。退出屏保会释放播放器。桌面空闲屏保和 `AerialDream` 复用此组件。

## 验证

现有自定义视频流程在 KKTV U86V9 / Android 9 上验证过手机上传、播放、自动切片、左右切片、确认键唤醒、删除后回退照片及重新导入。在更新后的 main 基线上，25 项 JVM 测试通过，包括上传存储边界和下载素材的路径白名单、摘要、长度、缺片及传输中断检查。

KKTV 上用并行 release 包预编译后，遥控器选中史努比卡片完成首次下载，12 段素材逐片校验通过。下载期间选择每日一图，下载完成后仍保留每日一图；再次选史努比可直接使用。抽查原始 HEVC 的主页空闲播放、按键暂停、恢复播放及暂停画面更新；同一页的「史努比 / 立即开始」可进入屏保，左右切片、确认键唤醒正常。换成每日一图后仍可单独启动史努比屏保；切回「视频」后，原有上传影片仍能播放。

五种语言的手机页均无脚本错误或 390px 横向溢出，「视频」上传入口仍在，原有 12 段上传的 ID 保留。两种 release 构建通过。更新到最新 main 后，在 KKTV 上再次上传一段约 4 MB 的视频成功，只删除该次测试生成的 ID，原有视频库不变。1.41 基线上的完整 lint 有 10 项上游已有错误，另有一项针对新增剩余空间检查的 `UsableSpace` 建议。

未验证：本机下载中断后重试/取消、逐一播放全部 12 段、系统级 Dream、其他电视解码器、长时间循环及待机唤醒。不代表所有 MP4/MOV 或 HEVC 透明素材都能播放。
